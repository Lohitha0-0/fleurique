# Fleurique 🌸

A pixel-art bouquet builder where you can pick flowers, arrange them into a bouquet, write a letter, and share it with someone special.
**[Live demo → fleurique.vercel.app](https://fleurique.vercel.app/)**

## What it does

1. **Pick your flowers** — choose from a collection of pixel-art flowers on the welcome screen
2. **Arrange** — drag, rotate, and resize your selected flowers on a bouquet canvas
3. **Write a letter** — attach a personal note (Dear / message / yours)
4. **Share** — copy a link that anyone can open to see your bouquet and read your letter

## Tech stack

- React 19 + Vite
- Plain CSS-in-JS (no UI library)
- Share links work via URL-encoded state (no backend needed)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for production

```bash
npm run build
npm run preview
```
